## Approved visual direction

- Modern polished mobile puzzle-game presentation
- Deep blue / neon game environment
- Glossy rounded controls and panels
- Bright green primary actions
- Blue secondary controls
- Gold stars and rewards
- Distinct Easy / Hard / Master visual identity
- Game-specific icons and decorative effects
- Consistent visual language across all 12 screens

## Asset package rule

The approved graphics package is screen-aware. Each screen has a list of required assets, while reusable graphics are stored only once as shared assets. Identical images must not be duplicated simply because more than one screen uses them.

Production assets must be individual/native high-quality files. Composite mockups are references and must not be cropped to create production assets.

## Change rule

This design remains locked until the owner explicitly requests a change. If a screen is changed later, only that requested screen and its corresponding asset package should be revised, followed by verification of affected screens.

## Image-generation permission

Do not generate, redraw, replace, or create project images unless the owner explicitly requests image generation/editing. A request to implement, debug, test, or update code is not permission to generate additional images.

## Implementation target

The approved design must be reproduced independently in iOS, Android, and Web while preserving the same visual design and the project's platform-independence rules.
