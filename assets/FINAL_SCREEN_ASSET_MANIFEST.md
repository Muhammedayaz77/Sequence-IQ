## Shared-asset rule

If an image is used on multiple screens, it is one shared production asset. Do not create multiple identical copies merely to place it in different screen folders.

## Source-of-truth rule

The owner-approved 12-screen mockup is the visual source of truth. The screen design and its asset mapping must remain synchronized.

## Revision rule

A later owner-approved change to one screen requires regeneration/update of that screen's asset set and verification of every screen affected by shared assets.
